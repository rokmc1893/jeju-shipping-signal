# 시작·기기 검증 · 2026-11-19

`start.bat`과 `start.sh`는 로컬 거래 캐시와 빌드된 화면을 발견하면 그대로 사용한다. 캐시가 없을 때만 사용자의 허브 키를 받아 기본 품종을 수집한다. 브라우저는 서버가 준비된 뒤 연다. 실행 주소와 설정 절차는 [설치 매뉴얼](../docs_install_manual.md)에 있다.

| 환경 | 확인한 결과 |
| --- | --- |
| GitHub Actions Windows Server 2025 x64, Python 3.12 | 기존 가상환경과 `.env`가 없는 공백 포함 폴더에 소스·정적 화면·검사용 합성 캐시를 준비했다. `start.bat`으로 가상환경·패키지 설치, 화면 HTTP 응답, 당근 API 조회, 종료와 재시작 후 같은 단위·가격을 확인했다. 첫 실행 준비 25.56초, 재시작 2.08초다. 두 조회에서 합성 2,000원/kg을 확인했다. [Windows 검사 로그](https://github.com/rokmc1893/jeju-shipping-signal/actions/runs/44478896031/job/135406032445) |
| macOS 27.2.1, Mac17,13, RAM 24GB, Python 3.13.2 | 별도 새 폴더에서 Python 패키지를 설치하고 실자료 캐시를 조회했다. 외부 주소를 차단한 브라우저에서 당근 1,853원/kg과 2026-11-17 거래일을 확인했으며 외부 요청은 0건이었다. 연속 API 100회에서 오류 0건, p95 0.004초다. 계획의 30분 반복 조회는 별도로 실행 중이다. |
| macOS 캐시 없음 | 키와 캐시가 없는 별도 경로에서 예시 `.env`를 만들고 설정 방법을 안내했다. 예시 키를 유지한 두 번째 실행도 수집 없이 중단했다. |
| iPhone 17 시뮬레이터, iOS 27.2 | 로컬 API에 연결한 디버그 앱을 설치·실행했다. 당근 버튼을 터치해 1,853원/kg, 2026-11-17 거래일, 관망을 확인했다. 상태바와 결과가 겹치는 스크롤 문제를 수정하고 같은 터치로 다시 확인했다. |
| 갤럭시 크기 Android 에뮬레이터 | iOS 여백 변경 후 설치 앱에서 기본 품종 5개의 가격·거래일·비교·신호를 다시 확인했다. |

Windows의 첫 시도에서 한글을 출력하는 검증 프로세스가 영문 Windows의 기본 코드페이지에서 실패했다. 표준 출력과 오류를 UTF-8로 지정한 뒤 재시작 검사까지 통과했다. [첫 검사](https://github.com/rokmc1893/jeju-shipping-signal/actions/runs/44478624495/job/135405147029)

백엔드 101개 로컬 테스트와 프론트 빌드가 통과했다. 시작 변경의 코드 리뷰를 받았다. 앱 실행 파일과 데이터는 로컬 검증에만 사용했다.

센터의 Windows 11 실기, 보안 정책·설치 권한, 실제 아이폰·갤럭시의 조작은 추후 확인한다. Windows CI에서는 화면 제공과 API 조회를 검사했으며 기본 브라우저 자동 열기는 생략한 모드로 실행했다. GitHub 실행 환경의 설치 시간은 센터 PC의 측정값과 구분한다.
