# 출하 신호등 모의 심사와 제출 방향 · 2026-11-18 저녁

**주제를 유지하고 서비스의 약속을 좁힌다.** 기획서의 한 줄 소개는 “제주 월동채소 농가가 전국 도매시세의 변화와 자료의 한계를 직접 읽는 Agent”로 한다. 사용 지역은 제주이고, 측정값은 전국 공영도매시장의 품종별 거래다. 데이터는 농가 수취가·제주산 거래가격·향후 출하 수익을 측정하지 않는다. 당근·양배추를 최근 거래 시연에, 월동무를 판단 보류 시연에 사용한다. 검토에 참여한 AI 세 역할은 개발·심사 보조로 기록한다.

## 공식 기준과 현재 증거

전문가 원점수의 비중은 최종 평가의 70%다. 아래 점수는 현재 저장소와 검증 기록을 본 데이터·기술 심사 역할의 항목별 추정치다. 아직 완성된 제출 PDF·ZIP이나 비개발자 관찰 기록을 보지 못했다. 순위 예측이나 공식 채점에 쓰지 않는다. [DAKER 평가 기준·상세 일정](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=info&tab=schedule)

| 전문가 항목 | 배점 | 모의 점수 | 심사 근거와 점수를 바꿀 증거 |
| --- | ---: | ---: | --- |
| 주제의 타당성·창의성 | 15 | 10 | 농가의 한 질문과 사용자층은 분명하다. 흔한 시세판을 넘어서는 사례로, 전년보다 비싸지만 최근에는 하락한 당근의 두 비교를 한 화면에서 설명한다. |

| 편의성·실용성 | 25 | 14 | 큰 글씨, 품목 버튼, 원/kg 표시가 있다. 분석 결과가 엇갈린 경우와 자료 부족 모두 ‘관망’으로 보인다. 비개발자가 스스로 거래일·이유·보류 의미를 구별한 기록이 필요하다. |

동점은 Agent 기술성, 편의성·실용성, 필수 데이터 활용 순으로 가른다. 나머지 30%는 최종 제출 팀 간 ELO 쌍대 비교다. 상호평가에는 기획서만 공개된다. 최소 참여 투표 수 미달 시 투표·득표가 반영되지 않는다. 공개 평가 본문에서 최소 횟수의 숫자는 확인되지 않아 평가 시작 시 플랫폼 안내를 따른다. 전문가·상호 평가 모두 11/23 12:00 시작이며 상호평가는 11/27 10:00, 전문가는 같은 날 23:59 종료다.

## 규칙과 게시판에서 달라진 결정

아래 Q&A는 DAKER 공식 게시판에서 해당 글의 운영자 답변을 확인했다. 링크는 게시판으로 열리고 글 제목으로 답변을 찾을 수 있다. [공식 게시판](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board)

- **심사용 ZIP** — ‘제주데이터허브 공개 데이터의 이용조건(재배포) 확인 요청’과 ‘제주데이터허브 공개 Open API를 센터 PC에서 직접 호출하는 방식 문의’에서 공개 API 수집 스냅샷의 심사·센터 운영용 ZIP 포함을 허용했다. 공개 허브 1361의 검증 캐시를 제출 ZIP에 한정해 동봉하고 출처·기준일·가공 과정·무결성 값을 명시한다. GitHub·별도 제3자 재배포에는 포함하지 않는다. 센터 비공개 데이터는 별도 반출 승인 대상이다. 참가자용 목록·예시 xlsx는 제외한다.
- **실행 환경** — ‘AI Agent 개발 챌린지 데이터 활용·제출 가능 범위 및 평가용 PC 실행환경 문의’의 운영자 표기는 Windows 11 26H2, i7-8700, GTX 1060, RAM 32GB다. 공고에는 VRAM 3GB가 명시돼 있다. 설치·인터넷 사용이 가능하나 서명 없는 확장 모듈에는 허용 등록이 필요할 수 있다. ‘외부 주소 접속 관련 안내’에 따라 설치·갱신에 필요한 호스트와 의존성을 매뉴얼에 기재하고, 포함한 스냅샷과 정적 UI로 첫 조회를 검증한다. 실제 센터 PC 설치 결과는 여전히 미확인이다.
- **제출물** — 11/20 10:00 KST까지 갤러리에 기획서(15쪽 이내)와 ZIP을 제출한다. ZIP에는 실행 소스·프롬프트·도구, 설치/사용 매뉴얼, 데이터 명세, 결과·검증·한계 설명자료를 포함한다. 데모·GitHub·YouTube 링크는 ‘제출물(링크 항목)과 제출 마감 확인 문의’ 답변상 선택이다. 코드·설명·공개 기획서의 기능 범위를 일치시킨다. 최초 제출 전 최종본을 확인한다.
- **AI·키** — 개발에 사용한 모델과 역할, 기본 실행의 규칙·도구, 선택형 LLM의 사용 조건, 외부 API·자료·코드·라이브러리를 구분한다. 기본 제출 경로는 LLM 없이 동작한다. 허브 키는 발급·설정 방법만 제공한다. 평가용 외부 AI 키 예외는 기본 제출 경로에서 필요하지 않다.
- **참여·권리** — 개인·팀 중복 등록 제한과 팀 제출 시 팀장 전환을 확인한다. 타 대회 수상작·기존 공개 또는 상용 결과물의 그대로 재제출 제한, 적법한 자료 사용과 민감정보 제외를 점검한다. ‘규칙 탭 “결과물 소속” 문구와 동의사항 이용 허락 범위 문의’에서 운영자는 실제 제출 파일에 대한 비독점적 이용이며 비수상작도 적용된다고 설명했다. 참가 동의문과 답변을 함께 확인하고, 향후 활용 시 대회 제출작·수상작 표기 안내를 따른다. 11/30 결과 발표, 수상 시 12/7 제주테크노파크 발표·시상식 참석을 일정에 둔다.

## 상호평가 독자가 짚은 빈칸

비전문 도민·제출 심사 역할은 현재 저장소만으로 ELO를 추정할 수 없다고 판단했다. 심사 질문은 “시세판과 어떤 차이가 있는가”, “노란색이면 기다릴수록 이익인가”, “센터에서 다음 주에도 누가 갱신하는가”였다. 기획서 첫 두 쪽에 아래 두 사례와 실제 도구 실행을 넣고, 본문에 센터 담당자의 갱신 명령·주기·마지막 성공 시각 확인·실패 시 안내·키 및 쿼터 관리 절차를 적는다. 설치 문서의 과거 상자 가격 표현은 현재 화면과 맞춘다. R01~R09는 실행 시나리오의 출발점이며 독자의 이해를 확인하려면 별도의 사용자 관찰이 필요하다.

## 기획서에 실을 두 장면

1. **“당근은 작년보다 비싼데 왜 관망인가요?”** 11/18 조회 기준 마지막 자료는 11/17, 1,853원/kg이다. 작년 동기보다 104.4% 높지만, 최근 7거래일 평균은 직전 7거래일보다 8.0% 낮고 마지막 가격도 30거래일 평균 2,005원보다 낮다. 세 조건 중 하나만 충족한다. 비교 기간과 판단 근거를 보여주는 사례다.
2. **“월동무도 오늘 비교해 주세요.”** 마지막 거래 자료는 6/26로 145일 전이다. 마지막 관측값·날짜는 표시하고 11월의 전년 비교는 보류한다. 분석 결과가 엇갈린 당근과 자료가 부족한 월동무를 색 없이도 식별하도록 한다. 두 사례의 실제 실행 기록과 데이터 기준일을 함께 싣는다. [실자료 검증](DATA_VALIDATION.md)
