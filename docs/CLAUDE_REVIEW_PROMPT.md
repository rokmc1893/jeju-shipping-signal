# Claude에 전달할 프롬프트

아래 내용을 기존 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 대화를 알고 있는 Claude에게 전달한다. 코드 수정은 Codex가 맡는다. Claude의 기존 기획서와 대화 맥락을 확보하고 제출 문서의 표현·근거를 검토하는 작업이다.

---

「출하 신호등 — 제주 월동채소 편」을 Codex에 인계했다. 다음 작업을 해줘. 새로 실험하거나 확인하지 않은 사실은 만들지 말고, 기존 문서에서 확인한 사실과 추가 검증이 필요한 내용을 구분해줘.

1. 기존 Claude 문서 `https://claude.ai/artifact/T2FLyQnYQNRoCCA1sCEHA8`의 기획서 전체를 **복사하거나 파일로 저장할 수 있는 Markdown**으로 내보내줘. 기존 표·내용·출처를 유지하고 생략하지 말아줘. 가능하면 원본 PDF도 함께 제공해줘.
2. 기존 프로젝트 문서 `claude/jeju-challenge-decisions.md`가 있다면 함께 내보내줘.
3. 참가자 표기는 ‘개인 참가 — 유소민(기획·프론트·AI 백엔드 전담)’으로 정리해줘. 상자·망 무게는 아직 공식 근거를 확인하지 않았으므로 미확인 표시를 유지해줘.
4. 다음 현재 상태와 모순되는 표현을 찾아 수정안을 별도로 작성해줘. 현재 기본 CSV 캐시는 비어 있어 실데이터 5품목 E2E는 미완료다. 기존 당근 실측은 과거 인계 기록이다. 로컬 테스트 34개·프론트 빌드·npm audit 취약점 0개는 확인했지만, 합성 자료 검증을 실제 자료 검증으로 쓰면 안 된다. Windows CI와 센터 PC 직접 설치 검증도 구분해야 한다.
5. ‘환각 제거’, ‘완전 오프라인’, ‘GTX 1060 적재 가능’, ‘농가 수취가 기준’, ‘날씨 때문에 가격 상승’, ‘자체 평가 96점’을 외부 검증 결과처럼 쓴 곳이 있다면 근거 수준에 맞게 고쳐줘. 버튼 조회는 실제 LLM 0회이며 자유 질문에서만 의도 추출·설명을 선택 사용한다. 숫자와 색은 결정론 규칙으로 정한다.
6. 공식 대회 공고에서 확인한 제출 요구사항·마감·평가·데이터 이용조건·결과물 권리 조건은 원문 링크와 확인 날짜를 붙여 정리해줘. 직접 열 수 없는 자료는 확인하지 못했다고 적어줘.
7. 기존 문서를 바탕으로 데이터 활용 명세와 결과 설명자료의 초안을 Markdown으로 작성해줘. 미검증 수치·화면·사용자 반응은 `[검증 후 입력]`으로 남겨줘. 기획서 PDF는 15페이지 이내를 목표로 구성하되 실제 PDF를 확인하기 전 페이지 수를 확정하지 말아줘.

응답은 ① 원본 기획서 Markdown ② 결정 기록 ③ 수정이 필요한 주장과 근거 표 ④ 데이터 활용 명세 초안 ⑤ 결과 설명자료 초안 순으로 줘. API 키나 개인정보가 담긴 환경파일은 요청하거나 포함하지 말아줘.
